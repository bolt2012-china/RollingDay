# RollingDay todo 示例

每行一个待办，格式如下：

```md
- [ ] 标题 | 截止时间 | 优先级 | 备注
```

- `标题` 会被同步脚本计算为稳定 id；修改标题会生成新的 id。
- `截止时间` 建议使用 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM`，也可以留空。
- `优先级` 建议使用 `高`、`中`、`低`。
- `备注` 可选。

## Inbox

- [ ] 准备项目周报 | 2026-10-23 | 高 | 示例备注
- [ ] 整理阅读清单 | 2026-10-24 | 中 |
- [ ] 备份本周资料 |  | 低 |
- [x] 已完成的示例任务 | 2026-10-20 | 中 | 本地已勾选
